논문 도표 AR · 관리자 안내

관람자는 로그인 없이 도표를 비춰 영상·음원을 재생합니다. 등록은 저장소에 쓰기 권한이 있는 본인만 할 수 있습니다.

처음 한 번: GitHub 토큰 만들기

  1. GitHub에서 Junyyyong 계정으로 로그인합니다.
  2. Fine-grained personal access token 생성 화면을 엽니다.
  3. Resource owner는 Junyyyong, Repository access는 Only select repositories → webviewer로 선택합니다.
  4. Repository permissions → Contents: Read and write만 추가합니다. Metadata 읽기는 자동으로 포함됩니다.
  5. 만료일을 선택하고 생성한 토큰을 비밀번호 관리자에 보관합니다. 만료되면 새 토큰을 만들면 됩니다. 관람용 뷰어에는 영향을 주지 않습니다.
  6. 관리자 화면에서 토큰을 입력해 연결합니다. 토큰을 코드·파일·채팅에 붙이지 마세요.

도표 추가와 발행

  1. 이미지와 대응하는 영상·음원을 선택하고 추가합니다. 파일 하나당 25MiB까지입니다. 영상은 H.264 MP4를 권장하며 지원 브라우저에서 720p 자동 변환을 시도합니다.
  2. 추가·삭제는 이 브라우저의 미발행 자료로 저장됩니다. 다른 기기와 공유되지 않습니다. 브라우저 저장 공간을 지우면 미발행 자료가 사라질 수 있습니다.
  3. 발행하기를 누르고 완료될 때까지 창을 열어 둡니다. 도판 51개 인식 데이터 생성에는 시간이 걸릴 수 있습니다.
  4. GitHub 저장이 완료되면 Cloudflare Pages가 자동 배포합니다. 배포 완료까지 몇 분 기다린 후 관람 화면을 새로고침하세요. 저장 기록 확인은 GitHub 저장 여부이며 배포 성공 여부는 Cloudflare에서 확인합니다.

발행은 파일과 인식 목록을 한 커밋에 저장합니다. 중간 실패 시 기존 공개 자료를 유지합니다. 다른 기기나 코드 수정이 먼저 발행되면 덮어쓰지 않고 중단합니다. 이 경우 임시 자료를 지우기 전에 따로 보관하고 변경 사항을 확인하세요.

기존 Supabase 자료

초기 51개 자료는 이전 파일에 포함돼 있습니다. ‘기존 자료 가져오기’는 Supabase의 공개 읽기가 가능할 때 추가된 도표만 복사합니다. 같은 ID는 건너뛰며 기존 항목의 수정 내용을 덮어쓰지 않습니다. 25MiB 초과 파일은 원본을 받아 압축 후 새로 추가해야 합니다. 가져오기만으로 공개되지 않으며 발행이 필요합니다.

무료 운영 범위

Cloudflare Pages 무료 플랜과 기본 pages.dev 주소를 사용합니다. 결제수단이나 R2 구독이 필요 없습니다. GitHub와 Cloudflare의 사용량·정책 제한은 적용됩니다. 영상이 대량으로 쌓이면 저장소 용량을 점검하세요. 삭제한 파일도 Git 이력에는 남을 수 있습니다. Supabase는 복사한 자료와 관람 화면을 검증한 뒤 정리하세요.
